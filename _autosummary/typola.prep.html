typola.prep#

Data preparation: raw source → canonical Typology.

This subpackage is self-contained: you can use it without any of the probabilistic modeling code. The output of load(...) is a plain Typology (four pandas DataFrames) that can be analyzed with any tool you like.

counts(parameter, *, condition=None, parameter_conditions=None, drop_missing=True)[source]#

Count languages by code for a parameter, optionally conditioned.

Returns a Series indexed by Code_ID (for parameters that use codes) or by raw Value (when no codes are defined), with integer counts. Codes present in the parameter’s code table but not observed are included with count 0.

Parameters:

  • parameter (str) – Parameter ID or name (via parameter_id).

  • condition (Mapping[str, Any] | None) – Filter on languages columns, see filter_languages.

  • parameter_conditions (Mapping[str, Any] | None) – Filter to languages whose other-parameter values match, see filter_languages.

  • drop_missing (bool) – If True, ignore rows with NaN / missing / “?” values (common in Grambank).

Return type:

Series

filter_languages(condition=None, *, parameter_conditions=None)[source]#

Return Language_IDs matching language-metadata AND parameter-value conditions.

Parameters:

  • condition (Mapping[str, Any] | None) –

    Filter on languages columns, {column: value_or_iterable_or_callable}:

    • scalar (str / int / bool) → exact match

    • list/tuple/set → membership

    • callable → predicate applied to the column value

  • parameter_conditions (Mapping[str, Any] | None) –

    Filter to languages whose values for given parameters match. Keys are parameter IDs or names; values can be a single code ID, a Value, or an iterable of acceptable codes/values. Example:

    parameter_conditions={"83A": "83A-2"}            # OV order
parameter_conditions={"81A": ["81A-1", "81A-2"]} # SOV or SVO

  • IDs. (An empty/None condition + empty parameter_conditions → all language)

Return type:

Index

class typola.prep.TypologyStore(*, local_paths=None)[source]#

Bases: Mapping[str, Typology]

Lazy read-only mapping from source name → Typology.

Typologies are loaded on first access and cached in memory for the lifetime of the store. Unknown names raise KeyError — register new ones via typola.sources.register_source(...).

Example

>>> ts = TypologyStore()
>>> sorted(ts)           # ['grambank', 'wals']
>>> ts['wals']           # → Typology (downloads on first call)
>>> 'wals' in ts

Parameters:
